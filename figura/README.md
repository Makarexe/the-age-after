# figura — облако аватаров Figura для наших аккаунтов

Официальное облако Figura проверяет игрока через Mojang, поэтому с нашими аккаунтами аватары не загружаются и не видны другим игрокам. Здесь запускается [Sculptor](https://github.com/shiroyashik/sculptor) — открытый сервер для Figura (GPL-3.0). Он проверяет игрока через наш сервер аккаунтов:

1. Figura просит у облака код и передаёт его «нашему Mojang», то есть серверу аккаунтов. Это тот же вход, что и при подключении к Minecraft-серверу.
2. Облако спрашивает сервер аккаунтов, заходил ли этот игрок с таким кодом (`hasJoined`).
3. Если сервер аккаунтов подтверждает, облако пускает игрока.

Пускает только наши аккаунты: Mojang и Ely.by в `Config.toml` не указаны.

## Как развернуть на Railway

1. В проекте с сервером аккаунтов: **Create** → **GitHub Repo** → этот репозиторий.
2. В новом сервисе: **Settings** → **Root Directory** = `figura`. Сборка идёт по `Dockerfile`, healthcheck `/health` (см. `railway.json`).
3. Правой кнопкой по сервису → **Attach Volume**, путь `/app/data`. Здесь хранятся загруженные аватары; без тома они пропадут при каждом обновлении.
4. **Settings** → **Networking** → **Generate Domain**. Порт выставлять не нужно: `start.sh` слушает тот, что задаёт Railway.
5. Скопируйте полученный адрес (например, `figura-production.up.railway.app`). В сервисе **сервера аккаунтов** добавьте переменную `FIGURA_SERVER` с этим адресом (без `https://`).

Лаунчер (с версии 0.1.8) при каждом запуске игры прописывает этот адрес в `config/figura.json` (Figura → настройки → «Figura Cloud IP»). Остальные настройки Figura у игрока не меняются.

Чтобы проверить, откройте `https://<адрес>/health`: должно быть `ok`. В игре в меню Figura появится «Облако аватаров The Age After».

## Что важно знать

- Аватары, загруженные раньше в официальное облако, сюда не переносятся: игроки загружают их заново (Figura → «Загрузить»).
- Лимит аватара — 100 КБ, как в официальном облаке (`[limitations]` в `Config.toml`).
- Адрес сервера аккаунтов прописан в `Config.toml` (`authProviders`). Если он поменяется, поправьте его там.
- Версия Sculptor закреплена в `Dockerfile`. Чтобы обновить, поменяйте тег и проверьте `Config.example.toml` новой версии.
